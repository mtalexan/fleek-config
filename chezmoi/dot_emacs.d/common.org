#+TITLE: Common Emacs configuration

Chezmoi manages this file. Edit =~/.emacs.d/common.org=, then bring it back with =chezmoi re-add ~/.emacs.d/common.org=. A home-manager rebuild installs any new =use-package= forms from the emacs overlay. Rebuilds before re-add restore this file from the repo.

Emacs loads these files in order. Later files override earlier ones.

1. =common.nix.el=, generated by Nix for settings that need store paths
2. This file
3. =host.nix.el=, generated by Nix for this host
4. The host org under =hosts/=
5. =custom.el=, which Emacs writes from Customize and =package-install=

=:tangle yes= blocks are loaded. =use-package= forms in those blocks are installed by Nix. Omit =:ensure=. Forms with =:ensure nil= or =:disabled= are not installed. =custom.el= is not parsed by Nix. Copy a setting here, or into the host org, when it should be kept.

The startup screen can only be disabled from =init.el=.

* Language support
All Emacs-enabled hosts share native file-mode associations, Eglot settings, completion, and mouse settings. Nix installs language modes and supplies executable command variables through =common.nix.el=. Each mode's =use-package= declaration below owns its additional file associations, native =eglot-server-programs= entries, and startup hooks.

=M-x describe-mode= documents the current major mode. Customize =eglot-server-programs= to inspect or override server associations, and use =M-x eglot-events-buffer= to inspect a running server. Click Eglot's mode-line entry for its native navigation, refactoring, and diagnostics menu.

Mode hooks call =eglot-ensure= directly, including for remote files. Eglot handles startup through its native local and TRAMP support. Remote server entries must use commands available on the remote host, not local Nix store paths.

Emacs 31 requires trusted content for automatic Flymake diagnostics. Customize =trusted-content= to approve only your trusted project directories, then re-enable =flymake-mode=. No global trust override is applied.

* Completion
Corfu opens after two characters and 75 ms of idle time. Eglot's native completion metadata handles server trigger characters. Corfu's native Return and Tab bindings apply. Cape adds file paths and buffer-local words without scanning other buffers.

Automatic completion excludes special/comint buffers. Buffer size and minified filenames have no custom completion restrictions. Manual completion remains available. Popup timing excludes server computation and indexing.

* Mouse access
Native menus and the right-click context menu expose global, major-mode, minor-mode, project, version-control, and buffer actions. Eglot's mode-line menu exposes language-server actions. Graphical frames provide a toolbar, scrollbars, and clickable Corfu candidates. Keyboard bindings remain available.

Terminal frames enable =xterm-mouse-mode=. Your terminal and any tmux session must forward mouse events. Use the terminal's selection bypass gesture, commonly Shift-drag, to copy outside Emacs. Terminal Corfu candidate clicking is not supported upstream. Use =completion-help-at-point= in a buffer or =minibuffer-completion-help= in the minibuffer, then left-click a candidate in the native completion list. Full hover and graphical custom-editor parity is not available in a terminal.

** Jinja and other templates
Jinja files use template-aware syntax editing and =jinja-lsp=. =C-c l t= switches the same buffer to its host language and back. A double suffix such as =.yaml.j2= identifies the host using native file detection. For a single suffix or a different host, use =C-c l T=. Every configured major mode can be selected.

Eglot manages one language server per buffer. Seamless services for arbitrary hosts would require projected documents, source-position mapping, diagnostic filtering, and edit translation. This configuration keeps native major-mode switching instead. The host server sees the template source, so template delimiters can cause host diagnostics, and servers that reject template filenames may not provide semantic results. Switching does not render, rewrite, or save the template.

#+begin_src emacs-lisp :tangle yes
(use-package web-mode
  :defer t
  :mode (("\\.\\(?:j2\\|jinja\\|jinja2\\|sls\\)\\'" . fleek-jinja-mode)
         ("\\.\\(?:erb\\|rhtml\\|rhtm\\|hbs\\|hjs\\|handlebars\\|jade\\|pug\\|razor\\|cshtml\\|gotmpl\\|tmpl\\)\\'" . web-mode))
  :hook ((fleek-jinja-mode . eglot-ensure))
  :bind (("C-c l t" . fleek-template-toggle)
         ("C-c l T" . fleek-template-choose-host))
  :init
  (require 'fleek-template)
  (add-to-list 'eglot-server-programs
               (cons '((fleek-jinja-mode :language-id "jinja"))
                     fleek-eglot-jinja-command)))
#+end_src
